# Projects

One living-architecture handoff doc per active app, in Matt's existing P-HAND-001 format: mission,
architecture (screens + data store + roles), constraints and confirmed versions (link back to
`../reference/confirmed-versions.md`, note only the deltas specific to this app), decisions made
and why, code/prompt rules specific to this app, unresolved issues, and next actions.

Update at the end of a working session, not just at project start — the point is that a new chat
can pick up mid-build by reading this file instead of Matt re-explaining state.

Name each file `<app-name>.md` (e.g. `cryo-dewar-tracking-suite.md`, `transfer-log.md`).
